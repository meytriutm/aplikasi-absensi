# Aplikasi Absensi Berbasis Pengenalan Wajah

Aplikasi absensi berbasis web yang menggunakan teknologi pengenalan wajah untuk proses verifikasi identitas dan pencatatan absensi.

## Fitur

- Login pengguna
- Verifikasi identitas menggunakan pengenalan wajah
- Pencatatan absensi
- Riwayat aktivitas absensi
- Pengelolaan data pegawai
- Penyimpanan data menggunakan Firebase

## Tech Stack

- HTML
- CSS
- JavaScript
- Tailwind CSS
- Firebase

## Tentang Project

Project ini dibuat selama kegiatan Praktik Kerja Lapangan (PKL) sebagai salah satu pengalaman dalam mengembangkan aplikasi berbasis web dan mempelajari proses pengembangan aplikasi dalam lingkungan kerja.
